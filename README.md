# Hermes Agent Wiki

基于 Karpathy's LLM Wiki 模式的持久化知识库。
由 Hermes AI Agent 维护，自动编译、交叉引用、持续更新。

## 使用方法

### 在 GitHub 上浏览
直接在 https://github.com/ikeee/hermes-wiki 查看。

### 在 Obsidian 中打开
1. 克隆仓库到本地
2. Obsidian → 打开为 Vault
3. 安装 Dataview 插件获得更好的查询体验

### 目录说明
```
raw/        — 原始资料（文章、论文等，不可修改）
entities/   — 实体页面（人、组织、产品）
concepts/   — 概念页面
comparisons/ — 对比分析
queries/    — 查询结果存档
```
